# AI Chat History Documentation

This folder preserves the full, unedited AI chat history for this project, conforming to Section 7 of the AI Engineering Take-Home brief.

## Instructions:
1. Ensure all passwords, Hugging Face tokens, and private API credentials are replaced with `[REMOVED]` before pushing to the public repository.
2. If using web interfaces (ChatGPT, Claude, Gemini), generate public share links and paste them into `ai_chats/links.txt`.
3. If using local tools or editor extensions (Cursor, Copilot, Antigravity CLI), export or copy the transcript files directly into this directory.
